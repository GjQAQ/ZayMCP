Model
=====

The setup editors describe ZOS-API members once and reuse that description for reading and writing.

:class:`~zaymcp.zosapi.model.fields.Attribute` is one member copied into a result field.
:class:`~zaymcp.zosapi.model.fields.Rows` is a 1-based row list.
:class:`~zaymcp.zosapi.model.fields.Section` and :class:`~zaymcp.zosapi.model.fields.Listing` are System Explorer groups.
